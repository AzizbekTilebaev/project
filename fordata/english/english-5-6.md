# 5–6 klass — ne úyrenemiz?

> Sóylew + **grammatika**. Tolıq qoidalar: **5 gram.** / **6 gram.** tabları (QQ).

## Ózin hám kúnlik ómir

| Fraza | Qashan |
|-------|--------|
| *I live in …* | jasaw orını |
| *I get up at …* | rutin |
| *I like English. Do you?* | unam |
| *What do you look like?* | sırtqı kórinis |
| *She has long hair.* | sıpatlaw |

**Mashq:** «My day» — 6 gáp Present Simple.

## Úy, jumıs, kásip

**Sózler:** home, work, teacher, doctor, driver, farmer  

| Fraza |
|-------|
| *My dad is a teacher.* |
| *She works at home.* |
| *There is a table in the kitchen. There are two chairs.* |

## Bazar hám awqat (6)

| Fraza |
|-------|
| *I need some rice and an apple.* |
| *How much is the bread?* |
| *We cooked palov yesterday.* |
| *At the table: Pass me the salt, please.* |

**Mashq:** 8 awqat sózi + 4 gáp (*I bought… / I need…*).

## Grammatika — qısqasha (keyin tolıq tab)

| Tema | Estelik | Misal |
|------|---------|--------|
| *a / an / the* | birlik sanalatuǵın; anıq nárse | *a cat / an egg / the sun* |
| Plural | *-s / -es / -ies* | *books, boxes, babies* |
| Countable / uncountable | sanaw / sanaw emes | *two apples / some water* |
| Present Simple | habit | *He plays football.* |
| *do / does* soraw | | *Do you like tea? Does she live here?* |
| Past Simple (6) | keshe | *I helped my parents.* |
| Prepositions | jaylasıw | *in, on, under, next to* |

**Mashq (hápte):** grammar tabınan **1 qoida** → ózińizden **3 misal**.

## Qalay jumıs etiń

1. Jańa sózlikti awızeki aytıń (8–12 sóz).  
2. Bir qoida + 3 misal.  
3. Pair: *Do you like…? Where do you live?*
