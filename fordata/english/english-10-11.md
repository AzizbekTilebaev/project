# 10–11 klass — ne úyrenemiz?

> CEFR **B1**: tıńlaw–sóylew–oqıw–jazıw + grammatika. Tolıq kesteler: **10 Guide** tabı.

## Jumıs hám keleshek (10)

| Fraza |
|-------|
| *I want to be a …* |
| *I’m going to study …* |
| *You should prepare for the interview.* |
| *What are your plans for the future?* |

**Mashq:** job interview — 8 soraw + juwap; «My dream job» — 80–100 sóz.

## Ólke, adamlar, waqıt

| Fraza |
|-------|
| *Uzbekistan is famous for …* |
| *He was born in …* |
| *I spend two hours on homework.* |
| *First … Then … Finally …* |

## Passive hám modal

| Qurılıs | Misal |
|---------|--------|
| Passive | *English is spoken in many countries. This book was written in 2017.* |
| *should / must / can* | *You should sleep more.* |
| *be going to* | *I’m going to visit Samarkand.* |

**Mashq:** 5 gáp Passive (házir + ótken).

## Ekologiya hám densawlıq (11)

| Fraza |
|-------|
| *If we cut trees, the climate will change.* |
| *If I were you, I’d recycle more.* |
| *Global warming is a serious problem.* |
| *A healthy lifestyle means …* |

**Mashq:** Aral / pollution — sebep + nátiyje (6 gáp). Conditionals: 3 *if*-gáp.

## Turizm, biznes, xızmet (11)

| Fraza |
|-------|
| *I’m interested in travelling to …* |
| *What is marketing?* |
| *I’d like to make a complaint.* |
| *Could you help me, please?* |

## Ádebiyat hám ózin bahalaw (11)

| Fraza |
|-------|
| *My favourite book is … It is about …* |
| *I recommend this book because …* |
| *I’ve learned a lot from feedback.* |

**Mashq:** book review — 8–10 gáp.

## Grammatika (11 tiykar)

| Tema | Misal |
|------|--------|
| Conditionals I–III | *If it rains, … / If I were … / If I had …* |
| Relative clauses | *The book which I read …* |
| Present Perfect | *I have never been to …* |
| Tag questions | *You’re a student, aren’t you?* |

## Jazıw úlgileri

1. Opinion essay: pikir + 2 sebep + juwmaq.  
2. Formal letter: request / complaint.  
3. Short report: ecology yamasa healthy lifestyle.
