# 7–9 klass — ne úyrenemiz?

> Temalar keńeyedi: densawlıq, sport, media, jumıs. Maqset — **pikir + sebep** aytıw.

## Densawlıq hám sport

| Fraza |
|-------|
| *I don’t feel well.* |
| *I’ve got a cold / a temperature.* |
| *I play football twice a week.* |
| *I’m good at running.* |

**Mashq:** «My favourite sport» — 6–8 gáp.

## Kiyim, bos waqıt, sayaxat

| Fraza |
|-------|
| *What do you wear in winter?* |
| *In my free time I …* |
| *We went to … by bus / train.* |
| *Have a nice holiday!* |

## Media, kino, ilim (8)

| Fraza |
|-------|
| *I think … because …* |
| *In my opinion, …* |
| *My favourite film is … It is about …* |
| *Newspapers / the Internet / TV …* |

**Mashq:** bir jańalıq yamasa film — 5 gáp (Present yamasa Past).

## Baylanıs hám jumıs (9)

| Fraza |
|-------|
| *Could I speak to …, please?* |
| *I’ll call back later.* |
| *I’m applying for a job.* |
| *What are your strengths?* |
| *Dear Sir/Madam, … Yours faithfully,* |

**Mashq:** telefon dialogı (6 jup) yamasa 8 interview sorawı.

## Grammatika baǵdarı

| Tema | Misal |
|------|--------|
| Present / Past Simple | *I watch / I watched* |
| *can / can’t* | *I can swim.* |
| Compare | *bigger than / the best* |
| Passive (kirisiw) | *English is taught at school.* |
| Opinion + because | *I like it because it’s funny.* |

## Jazıw / sóylew

1. Paragraf: pikir + **2 sebep** (6–8 gáp).  
2. 1 minut awızeki: film / sport / holiday.  
3. Formal: qısqa e-mail (*Could you…?*).
