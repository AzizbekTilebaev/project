# Joqarı · Sintaksis hám qospa gáp

> Derek: Dáwletov M. — *Sintaksis* **2009** (151 bet, skaner); *Qospa gápler* **2010** (89 bet, skaner).  
> Maktab 7–9 sintaksis tiykarınan bar; bul MD — **joqarı struktura** + OCR keyin keńeytiw ushın skelet.

## 1. Sintaksis obyekti

1. **Sintaksis** — sóz dizbegi, gáp, gáp aǵzaları, olardıń baylanısı hám punktuaciya.
2. Birlikler: **sóz → sóz dizbegi → jay gáp → qospa gáp → tekst**.
3. Punktuaciya sintaksis penen birge úyreniledi.

## 2. Jay gáp

1. Gáp — tamamlanǵan oy; xabar / soraw / úndew / buyrıq.
2. **Bas aǵzalar:** baslawısh (kim? ne?), bayanlawısh (ne qıldı?…).
3. **Ekinshi dárejeli:** tolıqlawısh, anıqlawısh, pısıqlawısh.
4. Birgelkili aǵzalar; qaratpa / kiris sóz; birgelkili bayanlawısh.
5. Sóz dizbegi túrleri (atributiv, obektlik, jádáw…) — 2009 OCR menen tolıqtırıladı.

## 3. Qospa gáp (2010 monografiya skeleti)

1. **Dizbekli** qospa gáp — teń bólekler; dáneker mánileri (*hám, biraq, sebebi…*).
2. **Baǵınıńqılı** — bas hám baǵınıńqı bólek; baǵınıńqı túrleri (waqıt, sebep, shárt…).
3. **Dánekersiz** qospa gáp — intonaciya / irkilis; punktuaciya.
4. **Aralas** qospa gáp — dizbekli + baǵınıńqılı birge.
5. **Tuwra gáp** — avtor gápi menen; bas hárip / tire qádeleri (imla §82).
