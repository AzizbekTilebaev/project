# Joqarı · Imla qaǵıydaları (jamlangan)

> Derek: Dáwletov M. *Qaraqalpaq tili imla qaǵıydalarınıń jıynaǵı* (Bilim; OCR `dawletov-imla-2006`).  
> Latın álipbe. Mashq / nızam tariyxı qısqartılǵan. Sayt: `/qoidalar` → Joqarı.

## 1. Álipbe

1. Álipbede dawıslı hám dawıssız háripler bar.
2. **Dawıslılar:** a, á, e, i, ı, o, ó, u, ú (hám qosarlı -ıy/-iy/-uw/-úw/-ıw/-iw).
3. **Únli dawıssızlar:** b, d, g, ǵ, j, l, m, n, ń, r, v, w, y, z.
4. **Únsiz dawıssızlar:** f, h, x, k, q, p, s, t, c, ch, sh.
5. Túpkilikli sózlerde **e, o, ó** sóz basında **ye/wo** birikpesi emes — **e, o, ó** jazıladı (2009 ózgerisi alıp taslandı).
6. Á, ó, ú, ı, ǵ, ń — akut / ózgeshe tańbalar; apostrof qaptalında emes.

## 2. Dawıslılar imlası (tiykar)

| Hárip | Qoida (qısqasha) |
|-------|------------------|
| **Aa** | Esitilgen orında; ózlestirme sózlerde a→á dawıssı bolsa da **a** saqlanadı |
| **Áá** | Kóbinese birinshi buwın |
| **Ee** | Túpkilikli hám ózlestirme — barlıq orında **e** (ye emes) |
| **İı / Ii** | Esitilgen orında |
| **Oo / Óó** | Kóbinese dáslepki buwın; ó geyde ekinshi buwında |
| **Uu / Úú** | Kóbinese dáslepki buwın |
| **Qosarlı** | -ıy, -iy, -uw, -úw, -ıw, -iw — ekı tańba |

## 3. Dawıssızlar (tanlaw)

1. **B** — túpkilikli sózlerde bas/orta; ózlestirme aqırında p esitilse de **b** (*klub*).
2. **D** — awızeki t bolsa da jazıwda **d** (*zavod*).
3. **G / Ǵ** — g kóbinese jińishke; ǵ kóbinese juwan (geyde jińishke menen de).
4. **V, F, X, C, Ch** — tiykarınan ózlestirme sózlerde.
5. **H** — bas/orta; geyde tańlaq aqırında (*ah*).
6. **K / Q** — k jińishke, q juwan buwınlarda (ayırım ózlestirmelerden tısqarı).
7. **Ń** — orta hám aqır (*tań, jańa*).

## 4. Túbir + qosımta (morfofonologiya imlada)

1. **n + b…** — aytılıwda m bolsa da túbirde **n**: *nanbay*, *qanbadı* (nambay emes).
2. **n + l…** — aytılıwda l bolsa da **n**: *janlıq* (jallıq emes).
3. **n + q/k/ǵ/g…** — aytılıwda ń bolsa da **n**: *jonqa*, *qonǵan*.
4. **s/z + sh…** — aytılıwda sh bolsa da túbir **s/z**: *basshı*, *qosshı*.
5. **z + s…** — aytılıwda s bolsa da **z**: *jazsın* (jassın emes).
6. **q/k/p + dawıslı qosımta** — juwasaǵı jazıladı: *balıq→balıǵı*, *kitap→kitabı* (ayırım sózlerde ózgermeydi: *tip→tipi*).
7. Feyil **p + -ıp/-ip** → **w**: *tap→tawıp*.
8. Tartımda ayırım sózlerde qısıq dawıslı túsiredi: *xalıq→xalqı*, *murın→murnı* (biraq *awıl→awılı*).

## 5. Qosılıp / bólek / defis

1. **Qosılıp:** birikken atlar, uzaq birigip qalǵan sózler (*baspasóz*, *ómirbayan*), hár/hesh+almasıq (*hárkim*), qısqarǵanlar + qosımta (*QMUǵa*).
2. **Bólek:** mánili sıńarlar (*bas kiyim*), qospa feyil (*alıp keldi*), tirkewish/dáneker, sanlıqlar (*jigirma bir*).
3. **Defis:** jup sózler (*ata-ana*), tákirar (*taw-taw*), sinonim/antonim juwplar, arab cifra + qatarlıq (*5-mektep*; rimda defis joq).

## 6. Bas hárip hám ótkerme

1. Adam atı, jer-suw, mámleket, bayram, kitap/gazeta atları — bas hárip qádeleri.
2. Ótkerme — **buwın** boyınsha; bir buwınlı ótkermelanbaydı; jeke dawıslıdı bólek qaldırmań.
