# Joqarı · Morfologiya (sóz shaqapları)

> Derek: Dáwletovlar / Qudaybergenov **2010** (morfologiya bólimi); *Morfologiya* **1981** (skaner — OCR keyin keńeytiledi).  
> Maktab 5–6 / 7 morfologiya menen **qaytalanbastan** — joqarı struktura hám terminler.

## 1. Morfologiyaǵa kirisiw

1. **Morfologiya** — sózdiń grammatikalıq formaları, sóz shaqapları, olardıń kategoriyaları.
2. Joqarı kurs izbe-izligi: fonetika/leksika → morfemika/morfonologiya/sóz jasalıw/morfologiya → sintaksis.
3. Sóz shaqapları (tiykar): **atlıq, kelbetlik, sanlıq, almasıq, feyil, ráwish**, kómekshi shaqaplar (tirkewish, dáneker, modal, tańlaq, eliklewish…).

## 2. Atlıq

1. Zattıń atı; sorawlar: **kim? ne?**
2. Kategoriyalar: birlik/kóplik; seplik; tartım; betleniń (predicative).
3. Menshikli / ǵalabalıq; konkret / abstrakt.
4. Jasaliwı — jasawshı qosımtalar + qospa (qarań morfemika MD).

## 3. Kelbetlik, sanlıq, almasıq

1. **Kelbetlik** — qanday? qaysı?; salıstırıw dárejeleri (joqarı gramatika).
2. **Sanlıq** — neshe? neshinshi?; toplaw / shamalıq; cifra + imla.
3. **Almasıq** — atlıq/kelbetlik/sanlıq ornına; sepleniw (*maǵan, onı*).

## 4. Feyil

1. Is-háreket; bolımlı / bolımsız (*-ma/-me…*).
2. Betleniń, máhál (házirgi / ótken / keler), meyil.
3. Dárejeler (caus/pass/coop/refl — Apertium tagları menen baylanıslı).
4. Qospa feyil — bólek jazıladı (*alıp keldi*); imla §59.

## 5. Ráwish hám kómekshi

1. **Ráwish** — qalay? qashan? qayda?
2. **Tirkewish** — sóz↔sóz (*ushın, menen*).
3. **Dáneker** — aǵza↔aǵza / gáp↔gáp (*hám, biraq*).
4. Modal, tańlaq, eliklewish — joqarı morfologiya ishinde ayrıqsha.
