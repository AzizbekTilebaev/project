# Joqarı · Morfemika, morfonologiya, sóz jasalıw

> Derek: Dáwletov A./M., Qudaybergenov — *Házirgi QQ ádebiy tili. Morfemika…* (Bilim, **2010**);  
> Patullaeva G. — sóz jasalıw / morfemalıq qurılıs / tartım (OCR navbatında).  
> Maktab «túbir–qosımta» den **chuqurraq** terminologiya.

## 1. Morfemika

1. **Morfemika** — sózdiń eń kishi mánili bólekleri (morfema), túrleri, xızmetleri haqqında ilim.
2. **Morfema** — ulıwma birlik; **morf** — belgilı variant (*-ma/-me/-ba/-be/-pa/-pe*).
3. Morfemalar ekige:
   - **Túbir morfema** — leksikalıq máni; bólek turıwı yamasa affiks qabıllawı múmkin.
   - **Affiks morfema** — grammatikalıq máni; bólek turmaydı.
4. Affiksler:
   - **Sóz jasawshı** — jańa leksika (*balıq-shı*).
   - **Forma jasawshı / sóz ózgertiwshi** — kóplik, seplik, tartım, feyil formaları (*bala-lar*).
5. Tallawda semantikalıq baylanıs zárúr: *balıqshılıq* = balıq+shı+lıq; *adamgershilik* ≠ adam+ger+shi+lik.
6. Salıstırıw: bir morfema basqa sózlerde qaytalana alıwı kerek (*aqıl-lı / -siz / -góy*).

## 2. Túbir, tiykar, sóz

1. **Túbir** — onnan kishi mánili bólekke bólinbeydi (fonetikalıq buwın/seske bóliw múmkin).
2. **Tiykar** — jańa sóz yamasa forma jasawǵa tiykar bolǵan bólek (*balıq* → *balıqshı* → *balıqshılıq*).
3. Túbir ≠ sóz shaqabı hár waqıt birdey emes: *gúrek* (atlıq) / túbir *gúre* (feyil).
4. Qaraqalpaq — **agglutinativ**: affiks jalǵanǵanda túbir sesleri kóbinese saqlanadı (flektiv tillerge qaraǵanda ajıratıw ańsatıraq).

## 3. Morfonologiya (qısqasha)

1. **Morfonologiya** — fonologiyalıq birliklerdiń morfologiyalıq xızmeti (fonologiya ↔ morfologiya shegarası).
2. Túbir + dawıslı qosımta: únsiz → únli (*ek → egin*; *kitap → kitabı*).
3. Affiks variantları únleslik / dawıssız juwaplas boyınsha: *-lıq/-lik*, *-lar/-ler*, *-da/-de/-ta/-te*…
4. Imla menen baylanıs: aytılıw ózgerse de túbir háribi saqlanıwı (*basshı*, *nanbay*) — qarań `joqari-imla-qoidalar.md` §4.

## 4. Sóz jasalıw usılları

1. **Qosımtalaw (affiksaciya)** — eń ónimli: *-shı/-shi*, *-lıq/-lik*, *-lı/-li*, *-sız/-siz*, *-xana*, *-stan*…
2. **Birigiw / qospa** — eki (yamasa kóp) tiykardan: *tasbaqa*, *temir jol* (birikken vs bólek — imla).
3. **Jup / tákirar** — *ata-ana*, *taw-taw*.
4. **Qısqarıw** — *QMU*, *AQSH*.
5. Dáslep **jasawshı**, keyin **túrlewshi** (sırtqa qaray): *oqıw-shı-lar*.

## 5. Tartım (joqarı qabat)

> Derek qosımsha: Patullaeva G.S. *Tartım mánisin bildiriw usılları* (OCR `patullaeva-tartim`).

1. Tartım — predmettiń betke / predmetke **tiyisliligi** (meniki, seniki…).
2. **Morfologiyalıq usıl** — arnawlı tartım affiksleri (*-ım/-im*, *-ıń/-iń*, *-sı/-si*, kóplik variantları).
3. **Sintaksislik usıl** — iyelik sepliktegi betlew almasıq + atlıq (*bizdiń at*, *siziń úy*).
4. **Aralas usıl** — iyelewshi bet + iyeliniwshi birge kórsetiledi.
5. Tartım + seplik + betlik — atlıqtıń gáptegi baylanıs formaları; san (birlik/kóplik) — ayrı kategoriya.
6. Ayırım túbirlerde tartımda dawıslı túsiriw: *murın → murnı* (imla §42).
