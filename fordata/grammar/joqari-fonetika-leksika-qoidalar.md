# Joqarı · Fonetika hám leksikologiya

> Derek: Abdinazimov — fonetika+leksika (skaner); Berdimuratov — *Leksikologiya* **1994** (kirill pdftotext);  
> Pirniyazova / Shınnazarova — leksikologiya (OCR navbatında); Qurbanbaeva/Sultanova **2020** qo‘llanba.  
> Maktab 1–5 fonetika/leksika menen qaytalanbastan — joqarı anıqlamalar.

## 1. Fonetika / fonologiya (qısqasha)

1. **Ses** (fonema) — aytılıw birligi; **hárip** — jazıw tańbası.
2. Dawıslı / dawıssız; juwan / jińishke; únli / únsiz.
3. **Buwın** — hárbir buwında bir dawıslı; ashıq / tuyıq / qamaw.
4. **Únleslik** — juwan buwın → juwan qosımta; jińishke → jińishke (*-lar/-ler*).
5. **Assimilyaciya / juwasaǵı** — morfema shegarasında (qarań imla §37–41, morfonologiya).
6. Orfoepiya ≠ orfografiya: aytılıw ózgermesi hár waqıt jazıwda kórinbeydi.

## 2. Leksikologiya

1. **Leksikologiya** — sózlik quramı, sóz mánisi, sózlik birlikleri haqqında ilim.
2. **Leksema / sóz** — tiykarǵı ataw birligi; gápte sóz shaqabı hám aǵza xızmetin atqaradı.
3. Máni túrleri (joqarı terminler):
   - **Tiykarǵı / awısım** máni
   - **Metafora, metonimiya, sinekdoxa** (máni awısıw usılları)
4. **Sinonim, antonim, omonim, paronim** — leksikalıq qatnaslar.
5. **Frazeologiya / idiomatika** — turaqlı dizbekler (bólek jazıladı — imla §63).
6. **Leksika qatlamları:** túpkilikli; arab-parsı / orıs / xalıqaralıq ózlestirmeler; terminler.
7. **Aktiv / passiv** leksika; neologizm; arxaizm (joqarı kurs temaları).

## 3. Leksikografiya (baylanıs)

1. Orfografiyalıq sózlik — imla norması.
2. Túsindirme / awdarmalı sózlik — máni.
3. Sayt sózligi — túsindirme + morfologiya paneli menen isleyi; joqarı qoidalar — oqıtıw qabatı.
