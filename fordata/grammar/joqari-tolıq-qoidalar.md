# Joqarı oqıw · Házirgi qaraqalpaq ádebiy tili (jamlangan)

> Universitet / ilimiy qatlam. Maktab 1–11 den **ayrı**.  
> Derekler: `JOQARI.md`. Ishki fayl atları saytta kórsetilmeydi.

## Kurs izbe-izligi

1. **Fonetika + leksikologiya** (1-kurs)
2. **Morfemika, morfonologiya, sóz jasalıw, morfologiya** (2-kurs)
3. **Sintaksis + punktuaciya** (3-kurs)
4. **Imla** — ámeliy norma (barlıq kurslarǵa tiyisli)

---

## 1. Fonetika hám leksikologiya

1. Ses ≠ hárip; dawıslı/dawıssız; juwan/jińishke; únli/únsiz.
2. Buwın; únleslik — qosımta forması túbirge sáykes.
3. Leksikologiya — sóz mánisi, sinonim/antonim/omonim, frazeologiya, ózlestirmeler.
4. Máni awısıw: metafora, metonimiya, sinekdoxa.

---

## 2. Morfemika hám sóz jasalıw

1. **Morfema** — eń kishi mánili bólek; **morf** — variant (*-ma/-me/-ba…*).
2. Túbir morfema (leksika) vs affiks (grammatika).
3. Affiks: sóz jasawshı vs forma jasawshı / ózgertiwshi.
4. **Tiykar** — jańa sóz/forma ushın baza; túbirden keńirek bolıwı múmkin.
5. Sóz jasalıw: qosımtalaw, birigiw, jup, qısqarıw.
6. Tártip: jasawshı → kóplik → tartım → seplik (sırtqa).

---

## 3. Morfonologiya + imla shegarası

1. Dawıslı qosımta aldında q/k/p → ǵ/g/b (*kitap→kitabı*).
2. Aytılıw ózgermesi jazıwda túsirilmeytuǵın jaǵdaylar: *basshı*, *nanbay*, *jazsın*.
3. Feyil *p + -ıp* → *w*: *tawıp*.
4. Tolıq imla punktleri — imla bóliminde.

---

## 4. Morfologiya (sóz shaqapları)

1. Atlıq — seplik, tartım, kóplik, betleniń.
2. Kelbetlik, sanlıq, almasıq.
3. Feyil — meyil, máhál, bolımsız, dárejeler; qospa feyil.
4. Ráwish; tirkewish / dáneker; modal hám basqa kómekshi shaqaplar.

---

## 5. Imla (tiykarǵı)

1. Túpkilikli sóz basında **e, o, ó** — ye/wo emes.
2. Dawıslı/dawıssız háripler xızmeti; c/ch/x/f/v — kóbinese ózlestirme.
3. Qosılıp / bólek / defis jazıw (qospa sóz, jup, cifra).
4. Bas hárip; ótkerme — buwın boyınsha.

---

## 6. Sintaksis

1. Jay gáp: baslawısh, bayanlawısh; tolıqlawısh, anıqlawısh, pısıqlawısh.
2. Qospa gáp: dizbekli, baǵınıńqılı, dánekersiz, aralas.
3. Tuwra gáp; punktuaciya.
4. Tolıq monografiya extract — sintaksis/qospa gáp OCR keyin.
