# 5-klass · Qaraqalpaq tili — grammatika qoidaları (2015)

> **Derek:** Y. Berdimuratov, Q. Allanazarov, G. Patullaeva.  
> *Qaraqalpaq tili. 5-klass ushın sabaqlıq.* Tolıqtırılǵan hám qayta islengen basılımı.

**Eskertiw:** Dástúriy grammatika baǵdarı (fonetika → leksika → sóz jasaw → morfologiya → sintaksis). Mazmun + tiykarǵı qoidalar. Saytqa qosılmaǵan.  
Jańa 2024 basılımı menen taqqoslaw: `5-klass-taqqoslaw.md`.

## Qurılıs (mazmun boyınsha)

### Fonetika / grafika
- Sóylew aǵzaları; ses hám hárip; álipbe
- Dawıslı: juwan/jińishke; yerinlik/eziwlik; ashıq/qısıq
- Dawıssız: únli/únsiz; ayırım háripler; birgelkili dawıssızlar
- Buwın: ashıq, tuyıq, qamaw; ótkerme
- Orfoepiya; orfografiya

### Leksikologiya
- Sózdiń mánisi; kóp mánili; tuwra / awıspalı máni
- Sinonim, omonim, antonim
- Sózlikler

### Sóz jasalıw hám imla
- Túbir hám qosımtalar; jasawshı / túrlewshi / forma jasawshı
- Dórendi; túbirles
- Qospa: birikken, birikpegen, jup, qısqarǵan, tákirar
- Kóplik, tartım, seplik, betlik jalǵawları

### Morfologiya — atlıq
- Sóz shaqabı; atlıqtıń sepleniwi (ataw…orın); jay / tartımlı sepleniw
- Sintaksis xızmeti (bas / ekinshi dárejeli aǵza)

### Kelbetlik
- Qurılıs / jasalıw; qospa túrleri; atlıq ornına (zatlasıw)
- Sinonim / antonim; dárejeler (jay, arttırıw, salıstırıw)
- Anıqlawısh / bayanlawısh

### Feyil
- Betleniń; bolımlı / bolımsız
- Meyiller: buyrıq, tilek, shárt, maqset, anıqlıq
- Máhál: ótken, házirgi, keler
- Sinonim / antonim feyil

### Sintaksis
- Xabar / soraw / buyrıq / úndew gáp + irkilis
- Baslawısh, bayanlawısh; ekinshi dárejeli aǵzalar

---

## Tiykarǵı qoidalar (qısqasha)

1. Buwın túrleri: **ashıq, tuyıq, qamaw**; ótkerme — buwın boyınsha.
2. Qosımtalar xızmetine qaray: **sóz jasawshı, sóz túrlewshi, forma jasawshı**.
3. Atlıq **6 seplikte**; **jay** hám **tartımlı** sepleniw.
4. Feyil — **meyil** + **máhál** + betleniń.
5. Gáp mazmunına qaray 4 túr; bas hám ekinshi dárejeli aǵzalar.
