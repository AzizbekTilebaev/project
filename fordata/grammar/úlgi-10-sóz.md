### 10. **túsiriń**

| | |
|--|--|
| **Bóliw (motor)** | `túsir` + `iń` |
| **Túbir** | túsir |
| **Qosımtalar (motor)** | `-iń` → *tartım (II jaq)* dep belgilengen |
| **Eskertiw** | Kontekstte kóbinese **buyrıq** (*Este túsiriń!*): `-iń` = II jaq buyrıq. Motor házir tartım dep qoyǵan — **tekseriw ushın** qoyıldı. |
| **Derek** | feyil betleniń / buyrıq — `4`/`5` feyil |

## Qalay oqıladı (sayt úlgisi)

```
kitaplardıń
├─ kitap     ← túbir
├─ -lar      ← kóplik
└─ -dıń      ← iyelik seplik
   «Atlıq kóplik + seplik…»  [3–4 klass]
```

Nátiyje jaqsı bolsa — usı formatta UI / BookReader hint isleymiz.
