# Foydalanuvchi qo‘llanmasi

Qaraqalpaq til platformasi — brauzerda ochiladi. Ro‘yxatdan o‘tmasdan ham ko‘p narsa ishlaydi.

> To‘liq mahsulot xaritasi (nima qilsa nima bo‘ladi): **[FOYDALANUVCHI-SAYTI.md](FOYDALANUVCHI-SAYTI.md)**.

## Birinchi ochilish

1. Sayt manzilini oching (lokal: `http://localhost:3000`).
2. Bosh sahifada:
   - **Sózlik** — so‘z qidirish
   - **Oyınlar** — test, krossvord
   - **Qoidalar** — grammatika
   - **English** — ingliz fraza/mashq
3. Istasangiz 3 ta o‘yin eshigidan birini tanlang (first-run).

## Kunlik odat (5–10 daqiqa)

1. Bosh sahifada **kun so‘zi** — o‘qing, «check-in» bosing (ball).  
2. Shu so‘z bilan qisqa o‘yin (`Sozlik o‘yini`).  
3. Xohlasangiz bitta test yoki krossvord.

## Asosiy bo‘limlar

| Bo‘lim | Nima qiladi |
|--------|-------------|
| Sózlik | Qidiruv, harf, sevimlilar, morfologiya |
| Testlar | Savol-javob, ball |
| Krossvord | Tor to‘ldirish |
| Ádebiyat / Kitoblar | O‘qish, shoirlar |
| Tutor | Xatolarni mashq qilish |
| Qoidalar | QQ grammatika (kitob MD) |
| English | Ingliz fraza va mashq |

## Lotin / kirill

Yuqoridagi sozlamada yozuvni almashtiring — matnlar moslashadi.

## Akkount

- **Mehmon:** progress qisman brauzerda / anonim ID.  
- **Ro‘yxat:** sevimlilar, to‘liq tarix, qurilmalararo.  
- Parol unutilsa: «Parolni tiklash».
